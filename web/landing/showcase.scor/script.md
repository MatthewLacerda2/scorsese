# The landing page's examples (#904)

Three frames for the landing page's *What you can make* section: a promo, an
event recap and a 9:16 ad, each a page, two seconds apiece on one track so a
`scorsese still` at each one's 1.5 s mark is its picture (`make landing-hero`
from the repo root writes them). The businesses in them are made up; the frames
show the kind of video, not a customer's.
